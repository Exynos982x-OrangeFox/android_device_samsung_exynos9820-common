# OrangeFox Recovery common tree for Samsung Exynos 9820/9825 devices

Common device tree used by the [OrangeFox Recovery](https://orangefox.tech) device trees of the
Samsung Exynos 9820 and 9825 devices.

| Device | Codename | Tree |

| Samsung Galaxy S10 | beyond1lte | [android_device_samsung_beyond1lte](https://github.com/Exynos982x-OrangeFox/android_device_samsung_beyond1lte) |

| Samsung Galaxy Note10 | d1 | [android_device_samsung_d1](https://github.com/Exynos982x-OrangeFox/android_device_samsung_d1) |
| Samsung Galaxy Note10 5G | d1x | [android_device_samsung_d1x](https://github.com/Exynos982x-OrangeFox/android_device_samsung_d1x) |
